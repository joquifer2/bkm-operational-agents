# Contract en transicion - Informe de indicadores operativos de Planificacion de Demanda

## 1. Estado del documento

Este archivo se mantiene solo por trazabilidad historica.

Desde esta actualizacion, los contratos operativos por agente se integran en la spec del agente correspondiente.

Referencia canonica vigente para esta capacidad:

- `specs/02_spec_agente_principal_v0_1.md`

## 2. Regla vigente

No crear contracts separados por agente o skill salvo necesidad transversal.

Un contract separado solo aplica cuando define reglas globales para varias capacidades o para todo el repositorio.

Ejemplos de contract transversal:

- source of truth;
- precedencia documental;
- politica de memoria;
- politica de tools;
- human-in-the-loop;
- resolucion de conflictos entre fuentes.
